## 软件简介

### 什么是 GenericScope？

GenericScope 是一款专业的通用上位机软件，专为工业控制、测试测量、数据采集等应用场景设计。软件具有以下特点：

✨ **核心特性**
- 🔌 **多协议支持**：内置6种校验算法、10种数据类型，支持自定义协议配置
- 🔧 **插件化架构**：可扩展的插件系统，支持自定义功能模块
- 📊 **实时数据可视化**：实时曲线图、直方图、3D姿态显示
- 💾 **数据录制与回放**：支持CSV/JSON格式数据导出
- 🤖 **AI辅助配置**：智能协议生成，降低配置门槛
- 🎨 **主题切换**：支持亮色/暗色主题

### 应用场景

- **工业自动化**：设备控制与监控
- **测试测量**：传感器数据采集与分析
- **通信测试**：串口/TCP/Modbus协议测试
- **科研教学**：实验数据采集与可视化
- **产品开发**：硬件产品调试与验证

### 系统要求

**最低配置：**
- 操作系统：Windows 10 (64位)
- 处理器：Intel Core i3 或同等性能
- 内存：4GB RAM
- 硬盘：500MB 可用空间
- 显示器：1280×720 分辨率

**推荐配置：**
- 操作系统：Windows 10/11 (64位)
- 处理器：Intel Core i5 或更高
- 内存：8GB RAM
- 硬盘：1GB 可用空间
- 显示器：1920×1080 或更高分辨率

## 快速入门

### 5分钟快速上手

#### 第一步：启动软件

1. 双击桌面快捷方式或从开始菜单启动 `GenericScope.exe`
2. 软件启动后显示主界面

#### 第二步：连接设备

1. 在顶部工具栏选择 **COM端口**（如 COM3）
   - 软件会自动检测可用串口
   - 如果看不到您的设备，请检查驱动是否正确安装

2. 选择 **波特率**（如 115200）
   - 确保与设备设置一致

3. 点击 **Connect** 按钮
   - 按钮变为 "Disconnect" 表示连接成功
   - 状态栏显示连接状态

#### 第三步：查看数据

连接成功后：
- **左侧表格**：显示实时传感器数据
- **中间区域**：显示3D姿态可视化（适用于IMU设备）
- **右侧图表**：显示实时曲线

#### 第四步：录制数据（可选）

1. 勾选顶部的 **RecordLog** 复选框
2. 数据自动保存到 `data/` 目录
3. 文件名格式：`imu_data_yyyyMMdd_hhmmss.csv`
4. 取消勾选停止录制

### 数据格式说明

GenericScope 默认支持 CSV 格式的 IMU 数据：

```
ROLL,PITCH,YAW,AX,AY,AZ,GX,GY,GZ,MX,MY,MZ,TEMP
```

**字段说明：**
- ROLL：横滚角（°）
- PITCH：俯仰角（°）
- YAW：偏航角（°）
- AX/AY/AZ：加速度计 X/Y/Z 轴（m/s²）
- GX/GY/GZ：陀螺仪 X/Y/Z 轴（°/s）
- MX/MY/MZ：磁力计 X/Y/Z 轴（µT）
- TEMP：温度（°C）

**示例数据：**
```
0.12,1.45,89.23,0.05,0.12,9.81,0.01,0.02,0.00,24.5,10.3,8.7,25.3
```

## 协议配置

GenericScope 最强大的功能之一是灵活的协议配置系统，支持多种通信协议和数据格式。

### 打开协议配置

1. 点击右上角 **⚙** 设置按钮
2. 选择 **协议配置** 菜单项
3. 协议配置对话框打开

### 协议配置界面

```
┌──────────────────────────────────────────────────────────────────────┐
│ 协议配置                                                    [_][□][×]│
├──────────────────────────────────────────────────────────────────────┤
│ [协议1] [协议2] [协议3] [+新建] [-删除]                             │
├────────────────────────┬─────────────────────────────────────────────┤
│ ┌─帧格式配置──────────┐│ ┌─字段配置────────────────────────────────┐│
│ │ 协议信息             ││ │                                         ││
│ │ 帧结构               ││ │   [数据字段表格]                        ││
│ │ 校验配置             ││ │                                         ││
│ │ 其他配置             ││ │   [字段详情编辑]                        ││
│ └──────────────────────┘│ └─────────────────────────────────────────┘│
├────────────────────────┴─────────────────────────────────────────────┤
│ [导入协议] [导出协议] [生成协议] [测试协议]  [确定] [取消] [应用]  │
└──────────────────────────────────────────────────────────────────────┘
```

### 新建协议

#### 方式1：使用 AI 生成（推荐）

**适合场景：** 快速创建标准协议

1. 点击 **[生成协议]** 按钮
2. 在弹出的 AI 对话框中描述您的协议
3. 示例输入：
   ```
   我需要一个IMU协议，包含Roll、Pitch、Yaw三个浮点数据，
   使用CRC16校验，帧头是FFAA，帧尾是0D0A
   ```
4. AI 自动生成协议配置
5. 检查并点击 **[确定]**

#### 方式2：手动创建

**适合场景：** 特殊需求或精确控制

**步骤1：填写协议信息**
- **协议名称**：唯一标识（如 `IMU_Protocol_V1`）
- **版本号**：版本管理（如 `1.0.0`）
- **描述**：协议说明

**步骤2：配置帧结构**
- **帧头（HEX）**：帧起始标记（如 `FF AA`）
- **帧尾（HEX）**：帧结束标记（如 `0D 0A`）
- **长度位置**：长度字段在帧中的位置（字节偏移）

**步骤3：配置校验**
- **校验方式**：选择校验算法
  - None：无校验
  - Sum：累加和
  - XOR：异或
  - CRC8：8位CRC
  - CRC16-MODBUS：MODBUS标准CRC16
  - CRC16-CCITT：CCITT标准CRC16
  - CRC32：32位CRC

- **校验范围**：
  - FullFrame：整个帧（包含帧头）
  - AfterHeader：从帧头后开始（常用）
  - DataOnly：仅数据部分
  - Custom：自定义

- **字节序**：
  - LittleEndian：小端序（常用）
  - BigEndian：大端序

**步骤4：添加数据字段**

1. 点击右侧 **[添加]** 按钮
2. 填写字段信息：

| 参数 | 说明 | 示例 |
|------|------|------|
| **序号** | 字段索引 | 1 |
| **起始位置** | 字节偏移量 | 0 |
| **名称** | 字段名称 | Roll |
| **类型** | 数据类型 | float |
| **长度** | 字节长度 | 4 |
| **缩放因子** | 数值缩放 | 1.0 |
| **偏移量** | 数值偏移 | 0.0 |
| **单位** | 单位符号 | ° |
| **最大值** | 范围上限 | 180.0 |
| **最小值** | 范围下限 | -180.0 |
| **描述** | 字段说明 | 横滚角 |

**支持的数据类型：**
- int8 / uint8：8位整数
- int16 / uint16：16位整数
- int32 / uint32：32位整数
- float：32位浮点数
- double：64位浮点数
- mbyte：多字节整数（自定义长度）
- string：字符串

**步骤5：保存协议**

1. 点击 **[生成协议]** 按钮
2. 验证配置是否正确
3. 点击 **[确定]** 保存

### 测试协议

**为什么需要测试？**
- 验证协议配置是否正确
- 检查校验码计算
- 确认字段解析

**测试步骤：**

1. 点击 **[测试协议]** 按钮
2. 输入测试数据（16进制）：
   ```
   FF AA 0C 00 00 00 3F 00 00 80 3F 00 00 00 40 AB CD 0D 0A
   ```
3. 点击 **[解析]** 按钮
4. 查看解析结果：
   - ✅ 成功：显示解析的字段值
   - ❌ 失败：显示错误信息

### 导入/导出协议

#### 导出协议

1. 选择要导出的协议标签页
2. 点击 **[导出协议]** 按钮
3. 选择保存位置（JSON格式）
4. 文件保存成功

**导出文件示例：**
```json

  "name": "IMU_Protocol_V1",

  "description": "IMU数据协议",

  "frameFooter": "0D 0A",
  "checksumType": "CRC16_MODBUS",
  "checksumScope": "AfterHeader",
  "byteOrder": "LittleEndian",
  "fields": [
    {
      "index": 1,
      "elementHead": 0,
      "name": "Roll",
      "type": "float",
      "byteLength": 4,
      "scale": 1.0,
      "offset": 0.0,
      "unit": "°"
    }
  ]
}
```

#### 导入协议

1. 点击 **[导入协议]** 按钮
2. 选择 JSON 文件
3. 协议自动加载
4. 检查并保存

### 协议配置示例

#### 示例1：MODBUS RTU 协议

```

帧尾：无
```

```
帧头：FF AA
帧尾：0D 0A
校验方式：CRC16_CCITT
校验范围：AfterHeader

字段配置：
1. Roll   - float - 4字节 - 偏移0
```

## 故障排除

### 常见问题及解决方案

#### 1. 无法连接设备

**症状：**
- 点击 "Connect" 按钮后无响应
- 提示 "Failed to open serial port"

**可能原因及解决方案：**

| 原因 | 解决方案 |
|------|---------|
| 驱动未安装 | 安装设备驱动（通常在设备制造商网站下载）|
| COM端口被占用 | 关闭其他串口工具（如串口调试助手）|
| COM端口选择错误 | 在设备管理器中确认正确的COM端口号 |
| 波特率不匹配 | 确认设备波特率设置 |
| USB线缆故障 | 更换USB线缆或USB端口 |

**检查步骤：**

1. **确认设备已连接**
   - 打开 Windows 设备管理器
   - 展开 "端口(COM和LPT)"
   - 查看是否有您的设备（如 "USB Serial Port (COM3)"）
   - 如果显示黄色感叹号，说明驱动异常

2. **测试端口可用性**
   - 使用其他串口工具（如PuTTY）测试
   - 如果其他工具也无法连接，说明是系统或驱动问题

3. **重启设备和软件**
   - 拔出USB线，等待5秒后重新插入
   - 重启 GenericScope

#### 2. 数据显示异常

**症状：**
- 数据表格显示乱码
- 数值跳变
- 图表显示异常

**可能原因及解决方案：**

| 原因 | 解决方案 |
|------|---------|
| 协议配置错误 | 重新配置协议，确保与设备协议一致 |
| 校验码错误 | 检查校验方式和校验范围配置 |
| 字节序错误 | 尝试切换大端/小端序 |
| 数据格式不匹配 | 确认设备输出格式 |
| 缓冲区溢出 | 降低数据发送频率或增加缓冲区 |

**调试方法：**

1. **查看原始数据**
   - 使用串口调试助手查看原始数据
   - 确认数据格式

2. **测试协议配置**
   - 使用 "测试协议" 功能
   - 输入实际接收的数据（16进制）
   - 查看解析结果

3. **检查日志文件**
   - 打开 `logs/` 目录
   - 查看最新的日志文件
   - 搜索 "error" 或 "warning"

#### 3. 录制文件无法打开

**症状：**
- 找不到录制文件
- 文件损坏或为空

**可能原因及解决方案：**

| 原因 | 解决方案 |
|------|---------|
| 文件路径权限问题 | 以管理员身份运行软件 |
| 文件正在被占用 | 停止录制后再打开文件 |
| 磁盘空间不足 | 清理磁盘空间 |
| 录制时间过短 | 录制至少1秒后再停止 |

**检查步骤：**

1. **确认文件位置**
   - 默认位置：`GenericScope/data/`
   - 文件名格式：`imu_data_yyyyMMdd_hhmmss.csv`

2. **检查文件权限**
   - 右键文件 → 属性 → 安全
   - 确保当前用户有读写权限

3. **使用文本编辑器打开**
   - 不要使用Excel直接打开（可能格式错误）
   - 先用记事本打开检查内容

#### 4. 软件启动失败

**症状：**
- 双击图标无响应
- 提示 "找不到DLL文件"
- 闪退

**可能原因及解决方案：**

| 原因 | 解决方案 |
|------|---------|
| 缺少运行库 | 安装 Visual C++ Redistributable 2019 |
| 缺少 Qt 库 | 确保 `Bin/x64/Release/` 目录下所有DLL完整 |
| 配置文件损坏 | 删除 `Settings.ini` 重新启动 |
| 防火墙阻止 | 添加软件到防火墙白名单 |

**解决步骤：**

1. **安装依赖库**
   - 下载并安装 [Microsoft Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe)

2. **完整性检查**
   - 确认 `Bin/x64/Release/` 目录下文件完整
   - 重新解压或重新安装软件

3. **重置配置**
   - 删除 `Settings.ini` 文件
   - 重启软件（会自动生成新配置）

#### 5. 图表显示卡顿

**症状：**
- 曲线更新不流畅
- 界面响应慢

**可能原因及解决方案：**

| 原因 | 解决方案 |
|------|---------|
| 数据频率过高 | 降低设备发送频率或调整 X_Dot 参数 |
| 显示点数过多 | 减小 X_Range 或增加 X_Dot |
| 电脑配置低 | 关闭其他占用资源的程序 |
| 显卡驱动问题 | 更新显卡驱动 |

**优化建议：**

1. **调整图表参数**
   - X_Range：60秒 → 30秒
   - X_Dot：1 → 2 或 5

2. **降低数据频率**
   - 设备端调整发送频率
   - 1000Hz → 100Hz

3. **关闭录制功能**
   - 不需要录制时取消勾选 RecordLog

## 常见问题

### Q1: 支持哪些通信协议？

**A:** GenericScope 支持多种通信协议：
- **串口协议**：RS232、RS485
- **网络协议**：TCP/IP
- **工业协议**：MODBUS RTU/TCP
- **自定义协议**：通过协议配置系统支持任意二进制协议

### Q2: 可以同时连接多个设备吗？

**A:** 当前版本支持单设备连接。如需多设备支持，可以：
- 启动多个软件实例（不同COM端口）
- 使用插件系统开发多设备管理插件

### Q3: 数据录制有大小限制吗？

**A:**
- **单文件大小**：无限制（取决于磁盘空间）
- **建议**：单次录制不超过1GB，以便后续分析
- **长期录制**：建议定期分段录制

### Q4: 如何导出数据到 Excel？

**A:** 两种方式：

**方式1：直接打开（简单）**
1. 找到录制的 CSV 文件
2. 右键 → 打开方式 → Excel
3. 注意：可能需要调整格式

**方式2：导入向导（推荐）**
1. 打开 Excel
2. 数据 → 获取外部数据 → 从文本
3. 选择 CSV 文件
4. 按照向导完成导入

### Q5: 协议配置会保存吗？

**A:**
- ✅ 自动保存：所有协议配置自动保存到 `Settings.ini`
- ✅ 持久化：软件重启后自动加载
- ✅ 导出/导入：可以导出为 JSON 文件备份或分享

### Q6: 可以自定义界面布局吗？

**A:** 当前版本使用固定的三栏布局。未来版本计划支持：
- 可拖动面板
- 自定义布局保存
- 多显示器支持

### Q7: 支持 Linux 或 macOS 吗？

**A:** 当前版本仅支持 Windows 10/11 (64位)。跨平台支持在开发路线图中。

### Q8: 如何开发自己的插件？

**A:** 请参考开发者文档：
- `docs/plugin-development-guide.md`
- 示例插件源码：`core_plugin/core_plugins/`

### Q9: 数据采样率最高支持多少？

**A:**
- **理论上限**：取决于设备和PC性能
- **测试数据**：
  - 1000Hz @ 13字段：流畅运行
  - 10000Hz：可能出现丢包（建议硬件缓冲）

### Q10: 软件收费吗？

**A:**
- **基础版**：免费使用
- **专业版**：包含高级功能（联系技术支持）
