# TASK-013: 集成测试

## 任务信息

- **任务ID**: TASK-013
- **任务名称**: 集成测试
- **优先级**: P1（重要功能）
- **预估工作量**: 2小时
- **依赖任务**: TASK-011（所有功能完成后）
- **状态**: 待开始

## 任务描述

对整个监控面板功能进行全面的集成测试，验证所有功能模块协同工作的正确性。这是开发阶段的最后一个任务，完成后即可交付。

## 具体目标

1. 测试所有P0核心功能
2. 测试所有P1重要功能
3. 测试异常场景
4. 性能测试
5. 内存泄漏测试
6. 编写测试报告

## 测试场景

### 场景1：单通道监控（P0核心功能）

**步骤：**
1. 启动GenericScope
2. 配置IMU协议（包含Roll字段，单位"度"）
3. 激活协议
4. 点击监控面板"+"按钮
5. 在配置对话框中：
   - 选择Roll字段
   - X轴范围设置为60秒
   - X轴点数设置为2
6. 点击确定
7. 开始发送IMU数据（频率10Hz）
8. 观察图表显示

**预期结果：**
- [ ] 配置对话框正确显示Roll字段
- [ ] 图表成功添加到监控面板
- [ ] 标题显示"Roll (度)"
- [ ] X轴范围-60~0秒，刻度数为2
- [ ] Y轴自动缩放
- [ ] 曲线实时绘制
- [ ] 数据更新频率10Hz
- [ ] 无卡顿

**验收标准：** 全部通过

---

### 场景2：多通道监控（P0核心功能）

**步骤：**
1. 配置IMU协议（Roll、Pitch、Yaw、AccX、AccY、AccZ）
2. 依次添加Roll、Pitch、Yaw三个图表
3. 开始发送数据（100Hz）
4. 观察三个图表

**预期结果：**
- [ ] 三个图表纵向堆叠排列
- [ ] 滚动条正常工作
- [ ] 三个图表同步更新
- [ ] 每个图表显示正确字段数据
- [ ] 性能流畅，无明显卡顿
- [ ] 内存占用稳定

**验收标准：** 全部通过

---

### 场景3：编辑与删除（P0+P1）

- [ ] 超出30秒的旧数据被移除
- [ ] 继续接收新数据正常
- [ ] 删除后图表从界面消失

**验收标准：** 全部通过


### 压力测试
- 编写数据发送器脚本
  ```python
  import socket
  import time

  sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
  sock.connect(('localhost', 8080))

  while True:
      data = generate_imu_data()
      sock.send(data)
      time.sleep(0.01)  # 100Hz
  ```
