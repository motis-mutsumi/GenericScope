# 协议配置对话框新功能使用指南

## 功能概述

本次更新为协议配置对话框添加了两个重要功能：
1. **字段批量导入** - 从CSV/JSON文件批量导入字段配置
2. **协议测试** - 测试协议配置是否正确

---

## 1. 字段批量导入功能

### 功能说明

当协议包含大量字段时（如20+字段），逐个手动添加非常繁琐。字段导入功能允许您从外部文件批量导入字段配置。

### 支持的文件格式

#### CSV格式

**文件结构**：
```csv
name,type,elementHead,byteLength,scale,offset,unit,maximum,minimum,description,tip
Roll,float,0,4,1.0,0.0,°,180.0,-180.0,横滚角,Roll angle
Pitch,float,4,4,1.0,0.0,°,90.0,-90.0,俯仰角,Pitch angle
```

**字段说明**：
- `name` (必需): 字段名称
- `type` (必需): 数据类型 (int8/uint8/int16/uint16/int32/uint32/float/double/mbyte/string)
- `elementHead` (必需): 起始位置（字节偏移）
- `byteLength` (必需): 字节长度
- `scale` (可选): 缩放因子，默认1.0
- `offset` (可选): 偏移量，默认0.0
- `unit` (可选): 单位
- `maximum` (可选): 最大值
- `minimum` (可选): 最小值
- `description` (可选): 描述
- `tip` (可选): 提示信息

**示例文件**：`docs/field_import_example.csv`

#### JSON格式

**文件结构**：
```json
{
    "fields": [
        {
            "index": 1,
            "elementHead": 0,
            "name": "Roll",
            "type": "float",
            "byteLength": 4,
            "scale": 1.0,
            "offset": 0.0,
            "unit": "°",
            "maximum": 180.0,
            "minimum": -180.0,
            "description": "横滚角",
            "tip": "Roll angle"
        }
    ]
}
```

**示例文件**：`docs/field_import_example.json`

### 使用步骤

1. **准备导入文件**
   - 使用Excel或文本编辑器创建CSV文件
   - 或使用JSON编辑器创建JSON文件
   - 参考示例文件格式

2. **打开协议配置对话框**
   - 主界面 → 设置按钮（⚙） → 指令设置

3. **选择或创建协议**
   - 选择现有协议标签页
   - 或点击"新建协议"创建新协议

4. **导入字段**
   - 点击右侧"导入"按钮（字段配置区域）
   - 选择CSV或JSON文件
   - 选择导入模式：
     - **Yes** - 清空现有字段后导入
     - **No** - 追加到现有字段后
     - **Cancel** - 取消导入

5. **验证导入结果**
   - 检查字段表格中的数据
   - 确认字段数量和内容正确
   - 如有错误，可删除后重新导入

### 注意事项

- CSV文件必须包含表头行
- 必需字段不能为空
- 数据类型必须是支持的类型之一
- 字节长度必须是正整数
- 建议使用UTF-8编码保存文件

## 2. 协议测试功能

### 功能说明

协议测试功能允许您输入16进制测试数据，验证协议配置是否正确。这对于调试协议配置非常有用。

### 使用步骤

1. **打开协议配置对话框**
   - 主界面 → 设置按钮（⚙） → 指令设置

2. **配置协议**
   - 配置帧格式（帧头、帧尾、校验方式等）
   - 配置数据字段

3. **打开测试对话框**
   - 点击底部"测试协议"按钮
   - 如果配置有误，会提示错误信息

4. **输入测试数据**
   - 在"测试数据输入"区域输入16进制数据
   - 格式：`FF AA 01 02 03 04`（支持空格、换行分隔）
   - 或点击"加载示例"自动生成示例数据

5. **解析数据**
   - 点击"解析数据"按钮
   - 查看解析结果：
     - **状态标签** - 显示解析成功/失败
     - **校验码** - 显示校验码验证结果
     - **原始数据** - 显示输入的16进制数据
     - **解析结果表格** - 显示每个字段的解析值

6. **验证结果**
   - 检查字段值是否符合预期
   - 如果解析失败，检查：
     - 帧头/帧尾是否匹配
     - 数据长度是否足够
     - 校验码是否正确
     - 字段配置是否正确

### 测试示例

**协议配置**：
- 帧头：`FF AA`
- 帧尾：无
- 校验方式：无校验
- 字节序：小端序
- 字段：Roll (float, 0, 4字节)

**测试数据**：
```
FF AA 00 00 80 3F
```

**解析结果**：
- Roll = 1.0 (0x3F800000 = 1.0f)

### 注意事项

- 测试数据必须是有效的16进制字符（0-9, A-F）
- 数据长度必须足够包含所有字段
- 帧头/帧尾必须匹配配置
- 当前版本仅支持部分数据类型的解析（int8/uint8/int16）
- 完整的数据类型支持需要集成ProtocolParser

## 常见问题

### Q1: CSV导入失败，提示"格式错误"？

**A**: 检查以下几点：
1. 文件是否包含表头行
2. 必需字段（name/type/elementHead/byteLength）是否都存在
3. 数据类型是否正确（区分大小写）
4. 数值字段是否包含非数字字符

### Q2: JSON导入失败，提示"JSON解析错误"？

**A**: 检查以下几点：
1. JSON格式是否正确（使用JSON验证工具）
2. 是否包含"fields"数组
3. 每个字段是否包含必需属性
4. 字符串是否正确使用双引号

### Q3: 协议测试显示"解析失败"？

**A**: 检查以下几点：
1. 帧头是否匹配（区分大小写）
2. 数据长度是否足够
3. 字段起始位置和长度是否正确
4. 字节序配置是否正确

### Q4: 如何创建CSV文件？

**A**:
1. 使用Excel创建表格，另存为CSV格式
2. 使用文本编辑器（如Notepad++）直接编辑
3. 参考示例文件：`docs/field_import_example.csv`

### Q5: 导入后字段顺序错乱？

**A**:
- 导入后字段索引会自动重新分配
- 可以使用"上移"/"下移"按钮调整顺序
- 或在CSV/JSON文件中按正确顺序排列

## 技术细节

### 字段导入实现

**CSV解析**：
- 使用`QTextStream`读取文件
- 按行解析，逗号分隔
- 自动跳过空行
- 验证必需字段

**JSON解析**：
- 使用`QJsonDocument`解析
- 支持数组或对象格式
- 调用`jsonToField()`转换

### 协议测试实现

**数据解析**：
- 16进制字符串转字节数组
- 验证帧头/帧尾
- 按字段配置提取数据
- 简化的数据类型转换

**限制**：
- 当前版本仅支持部分数据类型
- 校验码验证为模拟实现
- 完整功能需要集成ProtocolParser
